# surface-sweep-showcase

Build a screenshot-led showcase from a corrected product. Install `surface-sweep` alongside this skill; it supplies the shared QA workflow.

Example: `Use $surface-sweep-showcase to fix the app and add a case study to my existing portfolio.`

Outputs: the corrected app, reviewed captures with provenance, and a working showcase at the requested destination. A later-showcase mention only preserves private evidence; it does not begin showcase construction. Missing browser/image capabilities prevent verified visual completion.
