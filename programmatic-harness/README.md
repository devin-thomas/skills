# Programmatic Harness

This optional skill guides an explicitly requested, local Codex session controlled through Agent Native. It includes a bounded two-turn proof and nonsecret evidence rules.

Installing the skill alone adds no project dependencies. To run the proof, follow [Codex setup](references/codex.md) to opt in and install a pinned Agent Native release in a disposable project. The script selects a temporary workspace itself and removes it after verification.

Cursor and cloud harnesses are deferred. This package contains no Cursor implementation and does not claim cloud acceptance.
