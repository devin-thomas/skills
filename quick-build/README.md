# Quick Build

For a small meaningful app: one compact design interview, an approved plan, implementation, and verified delivery. For larger or uncertain projects, choose [grill-to-build](../grill-to-build/SKILL.md).

```text
Use $quick-build to build a simple reading log. Keep the data local and deliver a runnable project.
Use $quick-build to resume my Starter Pack Phase 2 project from this handoff.
```

Standalone mode needs only the project's development tools and permissions. Templates are bundled. Deployment and account setup are conditional on the requested delivery. The skill works without other installed engineering skills.

Starter Pack mode preserves the curriculum's prerequisites, private progress, and verified closeout. It requires the matching official requirements and progress resources, or supplied instruction packets. It does not duplicate the curriculum registry or certify graduation from the standalone workflow.

## Review scenarios

- Standalone project with no Starter Pack state: proceed with project discovery; no curriculum setup gates.
- Supplied answers and existing plan: reuse them; no repeated interview or duplicate artifacts.
- Local-only request: produce a runnable build; no forced hosting account.
- Starter Pack resume: follow the matched curriculum snapshot and preserve saved outcomes.
- Missing curriculum resources: retain the resume point; no invented graduation or fallback bypass.
- Deployment failure: preserve the local build and report publishing incomplete.

These are behavioral review scenarios, not claims of automated agent execution.
