# Style

1. Open https://starter.devthomas.site/style and find the guide that matches the code's language or framework. Prefer the most specific match, such as React + TypeScript over TypeScript for React components.
2. Read that guide and apply its conventions to the code you write or review.
3. If no guide matches, say so and follow the repository's existing conventions. A guide marked "In progress" may be incomplete; apply what it covers.

Repository conventions and explicit user instructions take precedence over the guide where they conflict.
