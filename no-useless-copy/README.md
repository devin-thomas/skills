# no-useless-copy

Review UI wording for redundant labels, filler, and accidental implementation leakage while preserving necessary guidance and accessible names. No companion tools or skills are required for source review; inspect the rendered UI when available.

Example: `Use $no-useless-copy on this onboarding flow; preserve information a first-time user needs.`

Outputs: scoped copy edits and a concise account of removed duplication and preserved meaning. This is not a general prose-shortening or marketing rewrite skill.
