# SKP-004 — Resolve complete dependencies and immutable content snapshots

Status: implemented locally

Depends on: SKP-001, SKP-002

## Work

Build catalog validation, required-skill graph resolution, source allowlists, full resource-closure compilation, bundled loading, GitHub channel pinning and bounded verified cache reads. Source mode is saved per managed root; no daily npm release is needed for GitHub content changes.

## Done when

Both real dependency pairs resolve automatically. Missing/cyclic edges, private/unapproved source paths, invalid objects, malformed archives and missing resources fail before writes. A GitHub transaction uses one manifest view and one commit per allowed source repo.

## Verification

Run deterministic closure and source-port tests, including related links, no-dependency override, sourceRef movement, hash mismatch, offline bundle, source limits, and explicit latest failure without fallback.
