# SKP-007 — Explain installation health without changing it

Status: implemented locally

Depends on: SKP-005, SKP-006

## Work

Complete read-only doctor, concise normal output, --json/--verbose, standard exit behavior and actionable errors. Distinguish installed bytes, native registration, discovered status and invocation evidence. List external applications/access requirements without installing them.

## Done when

An empty state is useful, JSON mode never prompts, diagnostics do not mutate or scan credentials, degraded dependencies are visible, and native registration gaps never appear as green native success. Output works in narrow/no-color terminals.

## Verification

Non-TTY golden tests, path redaction, Unicode/spaces, NO_COLOR, empty state, conflict cases, and comparisons proving doctor does not change files or refresh content unexpectedly.
