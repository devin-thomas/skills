# SKP-013 - Mount a read-only loopback MCP endpoint

Status: not started

Depends on: SKP-002, SKP-008

## Work

Use `@uppercut-labs/agent-native@0.1.0` `createMcpHandler` to mount an opt-in Streamable HTTP `POST /mcp` listener on loopback only. Declare peer `@modelcontextprotocol/server@2.3.0`. Expose exactly `catalog.list` and `catalog.show` from the shipped public catalog. Keep the MCP entry point isolated from ordinary CLI imports.

## Done when

The listener does not start on import or during ordinary CLI use. It rejects non-loopback binding and exposes no local installation state or write capabilities. No new Agent Native release is required.

## Verification

Inspect the registered tool list and bind address in a local fixture. Probe non-POST behavior and confirm no writer is callable through the mount.

Record implementation evidence and remaining gates here.
