# SKP-006 — Update and remove safely without losing local changes

Status: partial - mixed-channel update pending

Depends on: SKP-005

## Work

Implement update by saved channel and remove by explicit-root/managed-reference ownership. Preserve modified files and shared dependencies. Promote explicitly added dependencies to roots. Native host updates/removals follow their verified contracts.

## Done when

A content-only GitHub change updates under the same CLI version. Removal retains dependencies needed by remaining roots/hosts. Modified or unknown files survive every failure. No mixed incompatible dependency revision is silently installed.

## Verification
