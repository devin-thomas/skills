# SKP-002 — Create an independently installable CLI baseline

Status: implemented locally

Depends on: SKP-001

## Work

Add the distribution subpackage beneath packages/skills-cli, using TypeScript/ESM and Node 22+. Implement help, list, show, one JSON envelope, and the uppercut-skills bin. Lock available tool versions and verify the published Agent Native 0.1.0 artifact before pinning it.

## Done when

A locally packed tarball installs outside the authoring repo and runs help/list/show without undeclared dependencies, host setup, network on bundled paths, or side effects during import.

## Verification

Typecheck, unit-test output/error shape, inspect npm pack file listing, and run the tarball from a fresh external temporary project. Record exact versions and hashes.
