# SKP-012 — Prepare the release and leave an honest handoff

Status: not started

Depends on: SKP-009, SKP-010, SKP-011, SKP-014

## Work

Finalize help/README examples, release checklist, migration notes and source compatibility policy. Obtain/record the owner-selected license and required notices. Prepare final npm tarball and public package metadata for review. Publish only after the owner authorizes the exact release.

## Done when

A release-ready artifact has reproducible bytes, complete six-host evidence, and the read-only MCP protocol checks; all public examples match implemented commands. Licensing and actual publication authority are explicit. The handoff distinguishes prepared artifacts from a live npm release.

## Verification

Reinstall the final tarball externally and rerun the primary flow. After separate future publication approval, verify the exact registry artifact/version and a fresh registry install. Until then mark public availability pending.

## Outcome

Implementation evidence pending. Record actual result, changed files, focused checks, and the exact remaining gate here. The ZIP-only delivery restriction applied to the earlier planning handoff.
